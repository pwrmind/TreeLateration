# TreeLateration — точная геометрия фрактального дерева

Консольное приложение на C#, моделирующее геометрию бинарного дерева с использованием **точной рациональной арифметики** (BigInteger).  
Позволяет:

- сгенерировать квадраты расстояний до трёх «маяков» (вершин равностороннего треугольника) для любого узла дерева, заданного путём спуска от корня;
- восстановить координаты узла по этим квадратам расстояний (трилатерация);
- определить уникальный ID узла в стандартной нумерации бинарных деревьев (`1`, `2`, `3`…).

Ключевая особенность — **полное отсутствие погрешностей округления** на любом уровне вплоть до 64-го, благодаря использованию дробей произвольной точности.

---

## Как это работает

### 1. Геометрия
Основание — равносторонний треугольник `ABC` со стороной `L`:

```
A = (0, 0)
B = (L, 0)
C = (L/2, L·√3/2)
```

Корень дерева расположен в центре треугольника:
```
root = (L/2, L/2 · √3)
```

Каждый шаг спуска влево или вправо:
- `Y` уменьшается на текущий размер шага `stepSize`;
- `X` изменяется на `–stepSize` (влево) или `+stepSize` (вправо);
- `stepSize` уменьшается вдвое.

Начальный `stepSize = L/4`.

Все координаты хранятся в виде `BigFraction` — точных рациональных чисел.  
Ордината дополнительно отделяет множитель `√3`: истинная `Y = fractionY * √3`.

### 2. Трилатерация
По трём квадратам расстояний `dA², dB², dC²` координаты точки восстанавливаются аналитически:
```
x = (L² + dA² - dB²) / (2L)
y = (L² + dA² - dC² - L·x) / (L·√3)
```
Формулы не требуют решения систем — дерево спроектировано так, что они вырождаются в линейные.

### 3. Индексация узлов
По восстановленным координатам определяется уровень дерева, а затем порядковый номер на уровне.  
ID узла = `2^level + index`, где `level=0` у корня (ID=1).

---

## Требование к параметру L

**`L` обязан быть степенью двойки** (например, `2^63`).  
При нечётном `L` (как `2^63 - 1`) квадраты расстояний становятся рациональными числами, не сводящимися к целым, что нарушает логику проверки целочисленности в методе `SquareDistanceTo`.  
Выбор `L = 2^k` гарантирует, что все квадраты расстояний — целые числа на любом уровне.

## Требования

- [.NET SDK](https://dotnet.microsoft.com/download) 6.0 или новее (можно собрать и под .NET Framework 4.6.1+, где доступен `System.Numerics.BigInteger`).

---

## Установка и запуск

```bash
git clone https://github.com/yourname/FractalTreeModel.git
cd FractalTreeModel
dotnet run
```

Приложение выполнит демонстрационный проход по пути `Left → Right → Left → Left → Right` и выведет:

- сгенерированные квадраты расстояний;
- координаты, восстановленные трилатерацией;
- уникальный ID узла.

---

## Изменение тестового пути

В `Program.cs` измените массив `path`:

```csharp
Step[] path = { Step.Left, Step.Right, Step.Left };
```

Можно задать любую комбинацию до глубины 64.

## Структура проекта

Весь код размещён в одном файле `Program.cs` для простоты изучения:

- **BigFraction** — дробь с сокращением и арифметикой.
- **ExactPoint** — точка с точными координатами, квадрат расстояния, учёт √3.
- **TreePathGenerator** — генерация расстояний по пути спуска.
- **FractalTreeTrilateration** — трилатерация и декодирование ID узла.
- **Program** — демонстрация работы.
